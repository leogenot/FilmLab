# FilmLab

A small native macOS photo editor focused on film rendering and color grading.

## Current prototype

- Opens JPEG, 16-bit TIFF, and RAW formats supported by the Mac's Core Image decoder, identifying RAW through the file's ImageIO type. Non-RAW files use a file-backed Core Image decode. Develop shows a sampled display-space near-white channel readout for JPEG input, so bright input limits remain visible after the film curve rolls off output highlights. Verified with a Sony ILCE-7M4 ARW at 4672 × 7008 pixels and a 3737 × 5606, 16-bit TIFF.
- Provides RAW white balance, a sampled input neutral-area correction for RAW and rendered files, non-RAW input tone, warmth and tint, pre-film shadow and highlight light controls, film-light warmth and tint before the stock response, up to eight radial, graduated linear, or painted local exposure and color areas, output exposure, contrast, saturation, creative warmth and green–magenta tint, a three-point output tone curve, and an optional output shoulder, plus Shot Exposure, Development and Amount for an exposure-dependent film response. Slider values can also be entered numerically; displayed rounding does not change saved precision until a value is edited. New RAW imports default to a linear decoder response with its global and shadow tone curves disabled; the decoder-rendered mode remains available. The Film workspace offers the original study stock and experimental Portra 400 and Ektar 100 density studies based on Kodak’s published negative curves. The Portra and Ektar studies have optional Portra Endura and Endura Premier paper response stages, respectively.
- Adds luminance-preserving vibrance, shadow, midtone, and highlight color timing, a hue-range selective color adjustment, and an eight-family Color Mixer with hue, saturation and luminance controls. The color controls default to off. Repeatable, luminance-weighted grain with adjustable spatial size, highlight-edge halation, and a restrained luminance-based Edge detail control are also available. All three texture effects default to off.
- New color timing uses deterministic hue vectors for consistent shadow, midtone, and highlight directions across Macs. Earlier saved grades retain their previous color timing. The Color workspace offers **Use consistent color timing** for an older grade; this can visibly shift any active tonal color grade, and Undo restores the earlier behavior.
- The Settings menu can copy and paste only the active workspace between photos. Pasting Film, Develop, Color, Local, Texture, or Framing is undoable and leaves the other workspaces as they were. In Library selection mode, a copied workspace can also be pasted to several selected photos with the same persistent batch backup and Undo Last Batch flow as a full grade. Develop transfer keeps each destination's RAW decoder mode, highlight recovery, white balance, and rendered-input corrections; Color transfer includes the copied grade's color timing version. A copied workspace stays available in the running app until another workspace is copied or the app quits.
- Saves non-destructive edits per source file in `~/Library/Application Support/FilmLab/Edits/`, flushes them when the app leaves the foreground, and automatically reopens the last available photo on launch. Edits follow a rename or move on the same volume; older path-keyed edits migrate when reopened. A path-keyed backup remains for cases where file identity changes but the path stays the same. The Open menu offers Command-O and up to ten recent photos. Clearing that list also stops automatic reopening on the next launch, without deleting photos or saved edits. If a saved edit file cannot be decoded, FilmLab preserves a recovery copy before allowing new edits to save; if the copy fails, saving pauses to protect the original record.
- Adds a local Library view with named catalogs, multi-photo RAW/JPEG import, thumbnail grids, filename search, persistent favorites with a filter, import-order or name sorting, and an editor filmstrip. Catalogs can be renamed, and photo references can be copied or moved between catalogs individually or as a selection. Select a photo in the strip or use Command–Option–Left/Right to move between available photos; each source keeps its own saved grade and Undo history. The selected thumbnail scrolls into view. Copy Settings in the editor, then select several catalog photos and use Paste to apply the look to them together. Select All adds the currently visible search and favorite results to the selection. Export Selected renders each selected photo with its own grade as JPEG or 16-bit sRGB/Display P3 TIFF into a chosen folder, reports failures, and supports stopping between photos. Existing output names receive a numeric suffix rather than being replaced. The active source photo is skipped during batch paste; each target keeps its RAW decoder and rendered-input controls. Undo Last Batch restores changed targets even after restarting the app, and identifiable pre-change copies remain under `Edits/BatchBackups/`. Catalogs store references to original files in `~/Library/Application Support/FilmLab/Library.json`; removing a catalog or a photo reference does not delete originals or edits.
- Includes an output luminance and RGB histogram with per-channel near-white readouts, a sampled count of rendered pixels outside sRGB before output conversion, a preview-only red/blue sRGB gamut warning, and a point inspector comparing decoded input with developed output in extended-linear RGB. The selected point stays marked and updates as edits change. The editor also has Before/After, a draggable split comparison, non-destructive quarter-turn rotation, ±15° straighten, crop ratios with position controls and draggable freeform crop bounds, bounded Undo/Redo, Copy/Paste Settings between photos, portable JSON look files, Reset Edits, an undoable reset button for each editor workspace, and a scrollable 100% source-pixel inspection mode. Workspace reset affects only that workspace's controls; Develop reset returns RAW white balance to camera values and linear decoding, while Color reset preserves an older grade's color timing version.
- Decodes imports and RAW white-balance changes off the UI thread, then renders previews asynchronously in sRGB, coalescing rapid control changes so the canvas stays responsive. Preview normally develops in a half-float working buffer; the persistent **Float preview** switch uses the same 32-bit float working format as export for closer processing parity, at higher memory cost. The on-screen image remains sRGB display output. Exports full-resolution sRGB JPEG, 16-bit sRGB TIFF, or 16-bit Display P3 TIFF in a separate background renderer.
- Waits for a pending RAW decoder change or photo import before allowing export, so an export cannot silently use the previous decoded image with newly selected input controls.
- Leaves the source photo unchanged, including when an export is given the source path. JPEG export writes atomically; TIFF export renders to a temporary file and replaces the destination only after a complete render. Both formats normalize orientation and EXIF pixel dimensions to the finished image while retaining available capture metadata. Copy/Paste Settings transfers the saved grade, local areas, texture and framing. The destination keeps its own RAW decoder mode, highlight recovery, camera white balance and non-RAW input settings.

The original study stock is a provisional response model. The Portra and Ektar density studies use approximate samples from Kodak’s separate published negative-density charts, followed by a provisional balanced positive transform. Each optional paper stage blends the provisional positive with negative density mapped through approximate red, green and blue curves from Kodak’s Portra Endura or Endura Premier paper sheet. Paper Exposure controls the paper’s light exposure, and Paper Strength controls the blend; existing edits default to 0 EV and 50%. This is an exploratory paper color response rather than calibrated color-paper reproduction. The spectral and print/scan stages remain incomplete; see `CALIBRATION-PLAN.md` for the reference data needed to validate them.

Existing saved RAW edits keep their chosen decoder mode. Reset Edits returns a RAW to linear input. JPEG and TIFF files retain their embedded color profile and enter the extended-linear working space at the precision the source provides. They are already rendered images: lost highlight detail or an unknown camera tone curve cannot be recovered from them. Non-RAW Input tone reshapes available luminance around linear 0.18 middle gray before the film stage. It is a manual approximation for baked rendering, not an inverse camera profile or recovery of clipped detail. Non-RAW input warmth and tint apply a Core Image color balance before the film stage; they are a visual correction rather than a reconstruction of RAW white balance or scene color. The JPEG near-white readout samples the decoded image after conversion to sRGB; it flags areas to inspect, but does not prove source clipping or sensor saturation.

Input neutral correction averages a 32 × 32 decoded-pixel patch chosen in Fit view and applies RGB gains before film processing. It preserves that patch's linear luminance and rejects very dark, near-white, or extreme samples. It is saved per photo and excluded when transferring a look. Choosing an area that was not neutral will create a color cast; on RAW it does not replace the decoder's camera white balance, and on JPEG it cannot reconstruct missing scene color.

Film-light warmth and tint are creative balances after input correction and local edits but before the stock response. They are included in copied settings and saved looks. They let the stock model react to a changed input color, while output warmth and tint finish the developed image. These controls are not measured illuminant or film spectral corrections.

Recovery copies preserve unreadable edit data for inspection. When a valid path backup exists, FilmLab restores it to a missing or damaged identity record and shows a notice. If neither record can be decoded, FilmLab cannot reconstruct those edits automatically. The editor can reveal a damaged record's recovery copy in Finder.

Save Look and Apply Look in the Settings menu transfer the grade, local areas, texture and framing through a versioned JSON file. The target photo retains its own RAW decoder mode, highlight recovery, camera white balance and non-RAW input settings. A look stores editing parameters, not a fixed image transform; the film response still changes with scene exposure. Different RAW and rendered-image input can make the same look appear different.

## Run

Open `Package.swift` in Xcode and run the `FilmLab` executable target. For a signed local release bundle, run `Scripts/build-app.sh` and open either `Dist/FilmLab.app` or the root `FilmLab.app` link to that same bundle. The script builds with SwiftPM in release mode, compiles and bundles the stitchable Core Image Metal library, signs the app ad hoc, and verifies the signature. On its first run with an older standalone root app, it moves that bundle into `.build/legacy-bundles/` before creating the link. Xcode's optional Metal Toolchain component is required to build that library; install it with `xcodebuild -downloadComponent MetalToolchain` if `xcrun metal` reports it missing. Direct SwiftPM development runs without bundled resources compile the same kernel source at runtime. This local build is not notarized for distribution to other Macs. Run `Scripts/verify-rendering.sh` to check the bundled kernels, neutral balance, exposure order, distinct stock response and pre-film tonal controls. Set `FILMLAB_TEST_RAW` and `FILMLAB_TEST_JPEG` to disposable image paths to include the real-image Fit-preview/export parity probe.

3. Validate the resulting positive output against legally usable reference scans across several exposures and lighting conditions.

## Current limits

The film response and texture kernels are provisional. Output Shoulder is a finishing control after the film, paper, color and texture stages; it compresses bright output while scaling RGB together. It is not a measured film shoulder and cannot restore detail clipped in a camera JPEG or RAW decode. Vibrance uses an RGB chroma estimate and leaves negative extended-gamut channels unchanged; it is a creative control, not a measured dye response or perceptual color model. Grain Size 0 preserves the earlier independent pixel noise for saved edits; new edits start at 1, which blends fine noise with a correlated pattern over roughly 2–3 source pixels. The signed app bundles precompiled stitchable Metal Core Image kernels; this removes runtime source compilation for that bundle, but broader Mac and GPU compatibility has not been tested. The app has three stock choices, tonal grading, radial and linear adjustments, and painted local masks. It does not have a fully calibrated emulsion-to-print transform. Local areas use normalized source coordinates and can alter exposure, warmth, and tint before the film stage. Radial areas can be inverted to target the surroundings; linear areas can be directed and inverted to target one side of a scene. Painted and erased strokes stay with source pixels through framing and save brush size per stroke. The temporary mask view follows rotation and crop, and Place on photo maps a click through rotation, straighten and crop back to the unrotated source. Position sliders remain relative to that source. Local color balance is a visual correction, not a calibrated spectral adjustment. The Color Mixer uses soft RGB hue ranges, not a measured film dye response. The 100% view renders the full source and allows scrolling, but very large images increase memory use while inspecting. Preview rendering uses a half-float working buffer by default, with an optional 32-bit float mode; export uses a 32-bit float working buffer before final output conversion. A tiled preview renderer is a future performance improvement. The TIFF exporter was verified on `LEO00403.ARW` at 4672 × 7008 and 16 bits per sample.

The editor uses a three-column dark layout: file and workspace navigation on the left, photo canvas in the center, and one focused control group on the right. The gamut readout samples a downsized extended-linear sRGB render before 8-bit display conversion and counts pixels with any channel below zero or above one. It is a diagnostic for possible JPEG output clipping, not a source clipping measurement or a guarantee that Display P3 TIFF can retain every flagged color. Framing offers Original, 1:1, 4:5, 3:2, 16:9, and freeform crops after rotation and straighten. Freeform bounds can be adjusted with sliders or dragged over the uncropped preview; export always uses the crop. Straighten crops inward to avoid empty corners, so larger angles discard more edge pixels.

The sRGB gamut warning uses the same developed, framed linear image as export before display conversion. Red marks pixels with a channel above one; blue marks a channel below zero. The colors appear only in the preview, including the After side of split comparison. They are not written to JPEG or TIFF exports or included in the output histogram. The warning does not diagnose sensor clipping, identify the camera JPEG's lost detail, or predict every Display P3 output value.

Edit identity combines the volume UUID where available, the filesystem file number, and creation time. A copy or a move to another volume is a new file to FilmLab; its grade will need to be transferred with Copy/Paste Settings or a saved look. Replacing a file atomically at the same path can change its identity, in which case the path backup restores the most recently saved grade. These records stay local to this Mac and are not a portable photo catalog.

Catalogs currently store local file paths. If an original is moved or renamed after import, its entry shows it as missing; choose Locate Original to reconnect it. When the replacement has no saved grade of its own, FilmLab transfers a valid path backup of the missing photo's edits. It preserves an existing grade at the replacement path. A decodable but inconsistent catalog index is backed up before FilmLab repairs missing selections, duplicate IDs or photo references, and blank names. Batch paste skips missing or damaged edit records and reports any photos it could not update. Undo Last Batch is stored in `~/Library/Application Support/FilmLab/BatchHistory.json` and remains available after restarting until another successful batch replaces it; it skips photos edited again afterward. Copied settings remain available inside the running app even if another control changes the macOS clipboard. Thumbnails decode off the UI thread, prefer embedded ImageIO previews, and use a bounded in-memory cache. Large RAW libraries can still take time to populate. Catalogs do not copy photo files, sync between Macs, or automatically find moved originals.

Favorites are stored by local photo path in the library index and shared when the same photo appears in several catalogs. Relinking moves the mark to the new path. Removing its last catalog reference removes the mark; moving a file outside FilmLab still needs Locate Original. Favorites are a simple keeper marker, not a rating, rejection, or metadata written into the image.

Batch export renders the saved per-photo grade without switching the open editor. It saves current edits before including the open photo and skips that photo if saving fails. Missing originals and edit records needing review are reported rather than silently exported with default settings. Exported filenames are unique within the chosen folder; they are not linked back to the catalog. Cancel stops before the next photo, while a current render may finish. The chosen originals must remain accessible at their saved paths; catalogs do not yet retain security-scoped bookmarks for files outside ordinary local access.
